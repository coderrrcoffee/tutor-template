# Web Design Skill

## Purpose

Create visually polished modern websites that feel intentionally designed rather than generated from a generic template.

## Visual hierarchy

Every page should have a clear hierarchy:

1. primary message
2. supporting information
3. primary action
4. secondary information

Users should understand the purpose of the page within a few seconds.

## Typography

Use typography as a major part of the design.

Prefer:

- clear heading hierarchy
- comfortable line heights
- readable paragraph widths
- intentional font pairing when appropriate
- strong contrast between headings and body text

Avoid:

- excessive font sizes
- too many font families
- overly condensed text
- giant walls of text

## Layout

Use:

- consistent content widths
- deliberate spacing
- clear section transitions
- balanced whitespace
- asymmetric layouts when appropriate

Do not make every section look like a collection of identical cards.

## Color

Use a restrained palette.

Usually establish:

- primary background
- secondary background
- primary text
- secondary text
- accent color
- interactive states

Avoid using many unrelated colors.

## Components

Common useful components include:

- Header
- Navigation
- Hero
- SectionHeading
- Button
- ReviewCard
- FeatureCard
- PriceCard
- FAQ
- ContactSection
- Footer

Only create a component when reuse or clarity justifies it.

## Animation

Animations should communicate hierarchy or interaction.

Prefer:

- subtle entrance animations
- hover states
- smooth transitions
- small movement

Avoid:

- excessive bouncing
- constant motion
- animation on every element
- animation that delays access to content

Respect prefers-reduced-motion.

## Visual quality

Before considering a page finished, inspect:

- spacing consistency
- alignment
- typography
- mobile layout
- button hierarchy
- section rhythm
- visual balance
- empty space
- interaction states
