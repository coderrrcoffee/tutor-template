# Шаблон сайта репетитора

Обезличенный шаблон премиального сайта частного репетитора. React + Vite, из зависимостей — только `react-router-dom`.

## Страницы

Главная, Обо мне, Занятия, Стоимость, Документы, Результаты, Вопросы, Контакты.

## Как менять контент

Все тексты, цены, отзывы и контакты собраны в одном файле:

```
src/content/site.js
```

Заглушки помечены квадратными скобками `[ ]` — их нужно заменить реальными данными. Код страниц при этом трогать не нужно.

Цвета и шрифты меняются в `src/styles/tokens.css`.

## Команды

```bash
npm install      # установить зависимости
npm run dev      # локальный запуск
npm run build    # сборка
npm run lint     # проверка кода
```

## Публикация

Сборка и деплой на GitHub Pages настроены в `.github/workflows/deploy.yml` (запускается при push в `main`). Подпапка сайта задаётся в `vite.config.js` (`base`).
